# 执业医师病例分析330题刷题工具

基于【番茄执医】病例分析330题真题速刷PDF，通过OCR识别 + AI解析，生成交互式刷题页面。

## 功能特性

- **325道病例分析题** + 11个章节大纲页，覆盖13个临床系统
- **交互式刷题**：自测模式（隐藏答案）、收藏、搜索、键盘快捷键
- **教学式解析**：诊断推理链条、关键指标解读、鉴别诊断分析、做题技巧
- **题干高亮**：自动标注诊断线索关键词，快速定位重点
- **章节导航**：按系统分类侧边栏，题号从1开始编号

## 使用方法

### 直接使用

打开 `output/quiz.html` 即可开始刷题，无需任何安装。

### 从PDF重新生成

```bash
# 1. 安装依赖
pip install pymupdf rapidocr-onnxruntime anthropic python-dotenv

# 2. 配置API（复制模板并填入密钥）
cp .env.example .env
# 编辑 .env 填入 ANTHROPIC_API_KEY

# 3. PDF切页
python split_pdf.py

# 4. OCR识别 + API解析（支持断点续跑、多线程）
python analyze_pages.py --workers 3

# 5. 生成刷题页面
python generate_html.py
```

输出文件：
- `output/quiz.html` — 刷题页面
- `output/ocr_compare.html` — OCR原文 vs 题干对比审查页面

## 项目结构

```
├── split_pdf.py          # PDF切页脚本（PyMuPDF，200DPI）
├── analyze_pages.py      # OCR分栏 + API解析（RapidOCR + Anthropic API）
├── generate_html.py      # 注入数据到HTML模板
├── quiz_template.html    # 刷题页面模板
├── .env.example          # API配置模板
└── output/
    ├── results.json      # 结构化题目数据（325题）
    ├── ocr_cache.json    # OCR识别缓存
    ├── quiz.html         # 刷题页面（可直接打开）
    └── ocr_compare.html  # OCR对比审查页面
```

## 技术要点

### OCR分栏识别

PDF页面为左右双栏排版（左侧题干、右侧参考答案）。通过文本块的X坐标中位数进行分栏（分界线X=1150@200DPI），确保题干和答案不混在一起。

### 300DPI增强OCR

对全部342页同时进行200DPI和300DPI OCR，保留文本更完整的版本。300DPI能捕获更多细节信息。
